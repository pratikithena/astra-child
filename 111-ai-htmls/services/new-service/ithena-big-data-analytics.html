ITHENA’s ONE Data Platform

ONE Data Platform framework

One platform that carries your data from the source connection all the way to insight in front of end users, layer by layer.

  1. 01

    Data source connectivity

    Provides a single interface for managing and configuring your data sources, while separating credential management from data usage.

  2. 02

    Data ingestion

    Access to several sources of data for ingestion and live streams, integrated to be available for organization, access and analysis. A single UI to connect, ingest and act.

  3. 03

    Data enrichment

    Builds a data lake that consists of metadata, upsert capabilities and multiple versions of reading consistency.

  4. 04

    Semantic layer

    A framework for discovering, analyzing and accessing complex data that reduces complexity, making it easier for end users to discover, learn, explore, access and analyze data.

  5. 05

    End user visualization

    Consistently visualizes the data by displaying insights on the status of metrics and key performance indicators (KPIs) for an enterprise.

  6. 06

    Realize true artificial intelligence

    Machine learning algorithms aren’t enough in the hands of data science teams alone; they are best at providing outcomes in an easy and demonstrable fashion to end users.
